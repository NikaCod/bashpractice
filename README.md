### Самостоятельная работа по Bash

## Описание

В этом репозитории собраны Bash-скрипты, выполненные в рамках самостоятельной работы.
Скрипты покрывают базовые возможности Bash: ввод/вывод, условия, работу с файлами и генерацию случайных данных.

## Список скриптов

| № | Файл | Что он делает |
| - | ---- | ------------- |
| 1. | `script1.sh` | Спрашивает имя и выводит привествие |
| 2. | `script2.sh` | Калькулятор: складывает два числа |
| 3. | `script3.sh` | Проверяет, чётное число или нечётное |
| 4. | `script4.sh` | Создаёт структуру веб-проекта |
| 5. | `script5.sh` | Считает количество строк в файле |
| 6. | `script6.sh` | Генерирует случайный пароль |
| 7. | `script7.sh` | Ищет файлы по расширению |
| 8. | `script10.sh` | Анализ репозитория GitHub через API |

## Как запустить

Скрипты запускаются через `sh` в Git Bash или в терминале.

```bash
sh script1.sh
```
